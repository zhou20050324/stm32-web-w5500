# stm32-web-w5500
基于 W5500 的嵌入式 Web 服务器与温度监控系统

> 开发时间：2026.03 ~ 2026.04

## 项目描述
设计并实现了一个可通过浏览器远程访问的嵌入式温度监控系统。设备通过 W5500 以太网芯片接入局域网，内嵌 Web 服务器提供实时温度显示与 LED 远程控制界面。温度数据由 STM32 内部传感器采集，DMA 自动搬运；历史最高温度存储于 W25Q64 SPI Flash，支持掉电保存与异常数据校验。网络协议栈和 SPI 驱动均采用寄存器级编程实现，代码无第三方依赖。

## 核心贡献
- 基于 W5500 寄存器级驱动，实现 TCP 通信与内嵌 HTTP 服务器，支持动态 HTML 生成和 URL 参数解析，可通过浏览器远程控制 LED 开关。
- 使用 STM32 内部温度传感器 + ADC DMA 实现温度采集，配合蜂鸣器实现超温报警。
- 编写 W25Q64 硬件 SPI 寄存器驱动，实现最高温度掉电存储、扇区擦除与数据校验。
- 前端采用 HTML/CSS 响应式设计，适配手机端访问，1 秒自动刷新保证数据实时性。
- 从底层驱动到应用层全链路独立开发，代码模块化分层（网络层、存储层、应用层分离）。

## 硬件平台
- MCU：STM32F103C8T6
- 以太网芯片：W5500
- 存储芯片：W25Q64

## 工程说明
- Keil‑MDK5 工程，`AutoProject.uvprojx`为主工程文件
- 全部驱动寄存器直接操作，不调用第三方库与SDK
